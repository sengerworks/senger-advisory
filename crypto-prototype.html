Milestone A · Trust Prototype

Private results the platform cannot read.

This page encrypts a sample Capacity Profile in your browser, stores only ciphertext in local browser storage, and restores it using a secret kept in the URL fragment.

01

Separate keys

One recovery secret derives independent authentication and encryption material.

02

Client encryption

AES-256-GCM encrypts and authenticates the profile before anything is stored.

03

Fragment recovery

The recovery secret follows #, so it is not included in HTTP requests.
