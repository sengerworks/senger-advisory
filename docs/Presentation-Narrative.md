# Presentation Narrative v0.1

## Opening Idea
Organizations rarely fail because strategy is wrong. They struggle because growth creates complexity faster than capacity evolves.

## Sequence
1. Growth creates complexity.
2. Complexity creates friction.
3. Friction creates value leakage.
4. Value leakage slows execution.
5. Most leaders prescribe before they diagnose.
6. Organizational Capacity must be measured before it can be expanded.
